# Проект по конкурсу проф мастерства

## Часть 1 - Frontend

Frontend в файлах `index.html`, `style.css` и `script.js`

## Часть 2 - Backend

Backend расположен в файлах `server.js`, зависимости и конфигурации запуска находяться в `package.json`
Postman конфиг для тестирования API расположен в корне под именем `auto-configurator.postman_collection.json`

## Заключение

В рамках проекта были реализованны функции выбора модели, комплектации и доп. опций. Были реализованны механизмы выбора одного варианта из нескольких доступных, а так же нескольких вариантов из нескольких доступных. На сайте присутствует система регистрации и входа позволяющая сохранить наборы у себя на аккаунте.
